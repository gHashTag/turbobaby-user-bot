# TurboBaby — бренд-ассеты (v1, черновик)

Сделано автономным циклом 2026-09-14 (таск #2 доски). Вектор, без шрифтов в знаке.

## Файлы

- `turbobaby-mark.svg` — квадратный знак 512×512: колесо + молния «turbo» + линии
  скорости. Читается в кружке аватара Telegram на 40px.
- `turbobaby-logo.svg` — горизонтальный локап: знак + TURBO (900 italic) / BABY.
  Текст пока `<text>` (зависит от шрифтов) — перед печатью/продакшеном конвертировать
  в кривые (`text to path` в Inkscape/Illustrator).
- `preview.html` — превью на светлом/тёмном/аватар-кропе.

## Как поставить аватар бота

API не умеет менять photo бота — только BotFather: `/setuserpic` → выбрать
@turboagent_bot → загрузить PNG 700×700 (растеризовать mark.svg). До этого
меню-кнопка и имя бота уже TurboBaby.

## Дальше (владельцу)

1. Глянуть `preview.html`, сказать правки (цвет/жирность/наклон).
2. Утвердить → конверт в кривые + PNG-экспорт 700/512/192.
3. `/setuserpic` в BotFather.
