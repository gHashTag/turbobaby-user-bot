   аплоад worktree молча срывался). После `railway up` — ждать SUCCESS, потом
   проверять `/health`, `/api/bikes`, логи на InvalidToken.
4. **main всегда зелёный для деплоя.** Каждый фикс — своя ветка + PR + merge.
   Красный clippy на main — предсуществующий (132 ошибки, clippy 1.98), не блокирует.
5. **Var-изменение триггерит автодеплой** последнего загруженного исходника —
   учитывать порядок: сначала код, потом токены/vars.
